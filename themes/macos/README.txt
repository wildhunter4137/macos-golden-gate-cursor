macOS 27 Golden Gate cursors for older macOS

1. Install Mousecape: https://github.com/alexzielenski/Mousecape
2. Double-click macOS27-GoldenGate.cape (or File > Import in Mousecape).
3. Select it and press Cmd+Return to apply.
Undo: Mousecape > Reset to Default.

If some cursors stay at the system default on Sonoma/Sequoia, use macOS27-GoldenGate-Compat.cape (see docs/INSTALL.md).
