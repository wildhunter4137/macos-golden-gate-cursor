macOS 27 Golden Gate cursors for Windows 10 / 11 - LARGE (1.1x)

Same cursors as the normal Windows package, drawn slightly larger.

Double-click install.bat and confirm the administrator prompt.
It copies the cursors, registers the "macOS 27 Golden Gate Large" scheme, activates it and reloads the
live cursor set - no further steps needed. It can be installed next to the normal package.

Static cursors contain 32-256 px images (pointer size 1-15); animated cursors contain 32-96 px.

Undo: choose "Windows Default" (or the normal scheme) in Mouse settings > Pointers and click Apply.
